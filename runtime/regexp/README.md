# garnet's regular expression engine

`docs/regexp_vm_design.md`. Linked only into programs whose generated C declares
`TSAOT_NEEDS_REGEXP` (`scripts/lib/regexp_link_flags.sh` compiles the two objects):

- `rx.h` — the engine's C API over plain buffers (compile, exec, the program's facts, the
  source escaping, the case tables), no runtime types: a C test driver and the native tier use it.
- `rx_parse.c` — the pattern parser (ES2025 syntax, Annex B in non-`u` mode, V8's error reasons),
  `rx_compile.c` — the AST to bytecode compiler and the analysis (min length, anchoring, the
  first-character set, a literal prefix), `rx_vm.c` + `rx_vm_body.h` — the search loop and the
  backtracking interpreter instantiated for Latin-1 and UTF-16 input, `rx_set.c` — the arena and
  code point sets, `rx_unicode.c` + `rx_unicode_tables.h` — case mapping and the `\p{}` tables
  generated by `scripts/gen_rx_unicode.py` (Unicode 17.0.0), `rx_engine.c` — the amalgamation.
- `rx_cli.c` — the test driver of `tests/regexp/rx_diff.mjs` (the engine against V8, no runtime).
- `ts_regexp_adapter.c` / `.h` — the RegExp objects (`TS_KIND_REGEXP`), the compile caches, the
  results, `test`/`exec`/`match`/`matchAll`/`replace`/`search`/`split`, the constructor,
  `RegExp.escape`, the prototype's accessors, the hooks the core runtime calls.
- `quickjs/` — the vendored QuickJS `libunicode` (String `normalize` / case mapping in
  `runtime/unicode`); libregexp is no longer vendored.
